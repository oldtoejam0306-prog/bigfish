# Mac 本地语音部署与测试报告

**日期：** 2026-11-02

**状态：** 本地生成链路已验证；扬声器播放及连续对话未验收

## 摘要

在 Mac M2、16 GiB 内存、macOS 26.3 上，已在专用目录 `~/dafeiyu-mac-voice` 部署并运行 Qwen3-TTS 的 MLX 版本。官方 Qwen3-TTS-12Hz-1.7B-VoiceDesign 权重从 Windows 侧复用，锁定到 revision `5ecdb67327fd37bb2e042aab12ff7391903235d3`，主权重与 speech tokenizer 的 SHA256 校验值分别为 `391e8db219f292c515297cdceeb43e4eae67cdde35fa57e79a6a8a532fca0522` 和 `836b7b357f5ea43e889936a3709af68dfe3751881acefe4ecf0dbd30ba571258`。主权重的 404 个张量均为 BF16。

本地中文语音生成可用，宝宝声偏柔和、语速较慢；开心、温柔、小委屈三句的听感符合用户偏好。认真句出现明显声音漂移，因此这些样本不能作为跨文本、跨情绪声线一致的证据。脚本可让模型进程保持加载，并支持流式生成及可选缓冲播放；`--demo` 非播放生成通过。真实扬声器播放、持续对话和端到端语音交互尚未验收，当前结果不能称为实时播放能力。

## 声音试听观察

用户偏好柔和、偏慢的宝宝声，以及开心、温柔、小委屈前三种表达。四句样本中前三句分别生成 4.71、5.41、4.93 秒，对应音频长度为 3.60、4.24、3.92 秒。认真句声音发生明显漂移，不能用前三句的听感推断其保持同一声线。

原 A 是 VoiceDesign 描述生成，不是固定 speaker ID。不同文本或情绪可能改变生成声线；跨框架也不能保证身份一致。因此，本次样本只支持描述偏好和局部听感观察，不支持声纹恒定或跨情境一致性结论。

## 性能记录

### 原短句及四句样本

- 原短句首次冷启动共 26.95 秒，其中模型加载 22.13 秒、生成 4.82 秒；输出音频长 0.88 秒。
- 同一短句热运行生成耗时 1.12 秒，输出音频长 0.80 秒。
- 四句样本前三句生成耗时为 4.71 / 5.41 / 4.93 秒，音频时长为 3.60 / 4.24 / 3.92 秒。
- 这些数据来自本机生成运行记录，不等同于扬声器端到端延迟。

### 温柔句与流式生成

| 模式 | 首段到达 | 总生成时间 | 音频长度 / 估算 |
| --- | ---: | ---: | --- |
| 整句生成（温柔句） | 5.25 秒 | 5.26 秒 | 音频长 4.24 秒 |

“预计断续”是根据音频块生成/到达时间推算的潜在播放空档，不是实际扬声器录音、听测或端到端播放测量。更短块长在该次记录中降低首段等待，但总生成时间略增，估算断续也更长；不能据此宣称稳定实时体验。

### 内存

记录到 MLX 峰值 5.04 GiB、进程最大 RSS 1.21 GiB；统计口径不同，不能直接相加。该记录未计入或推断其他应用的内存使用。Swap 采样为 0；这是采样时的观察值，不能外推为所有负载下均无 swap。

## 本地脚本与功能边界

已创建 `voice-local.py`，支持模型进程保持加载、流式生成及可选缓冲播放。`--demo` 非播放生成检查通过。实际扬声器输出、播放质量、连续多轮对话、长时间稳定性及端到端交互均未验收。

当前没有远程推理服务，也没有 QQ 自动发送链路。因此本地语音生成结果不能视为已接入机器人、已提供远程语音 API 或可自动向用户发送；当前可经现有 SSH 由助手操作本地生成。

## 磁盘空间变更

用户确认已删除 Strata Qwen3.8 约 95 GiB 模型及对应缓存，可用空间由约 17 GiB 升至约 112 GiB。该变更仅指这项已确认删除的模型与对应缓存，不代表其他模型或缓存已清理。
